# 本地化RAG问答系统项目

## 项目概述
本项目打造了一个本地化的RAG（Retrieval Augmented Generation，检索增强生成）问答系统。借助Ollama部署DeepSeek模型，搭配Hugging Face的嵌入模型，它能够在本地CPU环境下稳定运行。此系统可让用户依据私有文档开展智能问答，支持语义检索与基于上下文的问题解答，同时拥有友好的Gradio界面，极大方便了用户交互。

## 主要功能

### 向量库管理
自动处理文档并生成向量库，若向量库已存在则直接加载，同时支持安全的序列化和反序列化操作。

### 文档分块
运用递归字符文本分割器对文档进行分块处理，有效利用文本数据。

### 语义检索
通过向量库开展语义检索，找出和用户问题最匹配的文档段落。

### 问题回答
结合检索到的上下文，调用Ollama API向DeepSeek模型发起请求，生成问题的回答。

### 用户界面
提供Gradio界面，涵盖问题输入框、回答输出框、提交按钮和示例问题，方便用户使用。

## 技术栈

### 编程语言
Python

### 主要库
- **LangChain**：用于向量库管理、文本分割和文档处理。
- **Gradio**：构建用户界面。
- **Hugging Face Embeddings**：进行文本嵌入。
- **Requests**：与Ollama API通信。
- **JSON**：读取和处理文档数据。

### 模型
- **嵌入模型**：BAAI/bge-small-zh-v1.5
- **大语言模型**：DeepSeek - r1:1.5b（通过Ollama部署）

## 项目结构
- `main.py`：项目主程序，包含向量库初始化、文档处理、问题回答和Gradio界面启动等功能。
- `config.py`：配置文件，包含模型、检索和数据的相关配置信息。
## 使用
python main.py

## 注意事项
首次运行时，系统会自动处理文档并生成向量库，可能需要一些时间，请耐心等待。
请确保 Ollama 服务已在本地正常运行，并且部署了指定的 DeepSeek 模型。
由于使用了 CPU 模式，性能可能会受到一定限制，尤其是在处理大量文档或复杂问题时。
